# OpenCV Invisibility Demo

这是一个基于 OpenCV 的实时颜色分割与背景替换实验项目，也就是常说的“隐身术”效果。

项目通过摄像头读取画面，识别指定颜色区域，生成 mask 掩膜，再把这部分区域替换成提前准备好的背景图像。

## 技术分类

- C++
- OpenCV
- 摄像头视频读取
- HSV 颜色空间
- `inRange` 颜色阈值分割
- mask 掩膜
- 图像按位运算
- 图像融合

## 实现流程

1. 使用 `VideoCapture` 读取摄像头画面。
2. 使用 `cvtColor` 将 BGR 图像转换为 HSV 图像。
3. 使用 `inRange` 提取红色区域，生成二值 mask。
4. 使用 `bitwise_not` 得到红色区域以外的反向 mask。
5. 使用 `bitwise_and` 分别提取背景区域和人物区域。
6. 使用 `add` 将两部分图像融合，得到最终画面。
