# C++ / Qt / OpenCV Learning Lab

这个仓库用于记录我在大学期间学习 C++、Qt、OpenCV 和嵌入式相关技术时完成的小项目与实验。

目前仓库里的内容以学习 demo 为主，重点不是堆代码量，而是把每个技术点真正跑通、理解清楚，并逐步整理成可以展示的项目。

## 项目目录

| 目录 | 分类 | 内容 |
| --- | --- | --- |
| `opencv-invisibility-demo` | OpenCV 图像处理 | 基于 HSV 颜色分割、mask 掩膜和背景替换实现的隐身术 demo |
